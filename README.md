# jdgm456.github.io
Application 6 of Real Time Systems

Description:
In this project we develop the embedded software that implements several RTOS tasks that 
allow for a Lockheed Martin Fighter Jet's subsystems to operate in real time.
Several real time tasks are implemented that help the Jet realize safety critical missions.
Such as barometer air pressure readings that give warnings when exceeded past a threshold.
And a Ejector button.
